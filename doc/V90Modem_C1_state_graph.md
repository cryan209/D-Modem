# V90Modem C1 State Graph

## Nodes
- `ENTRY`
- `INIT_EMBEDDED_MP_CP`
- `DEBUG_CONSTRUCTION_MSG`
- `PRINT_TITLE`
- `BUILD_SHARED_BLOCKS`
- `DISPATCH_SIDE`
- `BUILD_MODULATOR`
- `BUILD_DEMODULATOR`
- `SIDE_INVALID`
- `RETURN`

## Edges
- `ENTRY -> INIT_EMBEDDED_MP_CP`
- `INIT_EMBEDDED_MP_CP -> DEBUG_CONSTRUCTION_MSG` when `debug_level > 1`
- `INIT_EMBEDDED_MP_CP -> PRINT_TITLE` when `debug_level <= 1`
- `DEBUG_CONSTRUCTION_MSG -> PRINT_TITLE`
- `PRINT_TITLE -> BUILD_SHARED_BLOCKS`
- `BUILD_SHARED_BLOCKS -> DISPATCH_SIDE`
- `DISPATCH_SIDE -> BUILD_MODULATOR` when `side == 0`
- `DISPATCH_SIDE -> BUILD_DEMODULATOR` when `side == 1`
- `DISPATCH_SIDE -> SIDE_INVALID` otherwise
- `BUILD_MODULATOR -> RETURN`
- `BUILD_DEMODULATOR -> RETURN`
- `SIDE_INVALID -> RETURN`
