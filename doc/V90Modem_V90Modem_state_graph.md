# V90Modem::V90Modem State Graph

## Nodes
- `ENTRY`
- `INIT_EMBEDDED`
- `DEBUG_ROLE_MSG`
- `PRINT_TITLE`
- `ALLOC_SHARED`
- `DISPATCH_SIDE`
- `BUILD_MODULATOR`
- `BUILD_DEMODULATOR`
- `SIDE_INVALID`
- `RETURN`

## Edges
- `ENTRY -> INIT_EMBEDDED`
- `INIT_EMBEDDED -> DEBUG_ROLE_MSG` when `debug_level > 1`
- `INIT_EMBEDDED -> PRINT_TITLE` when `debug_level <= 1`
- `DEBUG_ROLE_MSG -> PRINT_TITLE`
- `PRINT_TITLE -> ALLOC_SHARED`
- `ALLOC_SHARED -> DISPATCH_SIDE`
- `DISPATCH_SIDE -> BUILD_MODULATOR` when `side == 0`
- `DISPATCH_SIDE -> BUILD_DEMODULATOR` when `side == 1`
- `DISPATCH_SIDE -> SIDE_INVALID` otherwise
- `BUILD_MODULATOR -> RETURN`
- `BUILD_DEMODULATOR -> RETURN`
- `SIDE_INVALID -> RETURN`
